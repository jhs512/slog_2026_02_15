# Triage 라벨

스킬들은 다섯 가지 표준 triage 역할로 말합니다. 이 파일은 그 역할들을 이 저장소 이슈 트래커에서 실제로 쓰는 라벨 문자열에 매핑합니다.

| mattpocock/skills 라벨       | 우리 트래커 라벨      | 의미                              |
| -------------------------- | -------------------- | -------------------------------- |
| `needs-triage`             | `needs-triage`       | 메인테이너가 이 이슈를 평가해야 함   |
| `needs-info`               | `needs-info`         | 제보자의 추가 정보를 기다리는 중     |
| `ready-for-agent`          | `ready-for-agent`    | 완전히 명세됨, AFK 에이전트 준비 완료 |
| `ready-for-human`          | `ready-for-human`    | 사람이 구현해야 함                  |
| `wontfix`                  | `wontfix`            | 처리하지 않음                      |

스킬이 역할을 언급하면(예: "AFK 준비 triage 라벨을 붙여라"), 이 표에서 대응하는 라벨 문자열을 사용하세요.

실제로 쓰는 어휘에 맞춰 오른쪽 열을 수정하세요.
