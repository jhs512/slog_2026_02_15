# 02 — 코어 스모크 시나리오

**What to build:** 사이트의 본줄기 사용자 여정이 브라우저에서 검증된다: 글 목록에서 글을 열어 읽고, 관리자가 로그인 화면으로 로그인하고, 로그인 사용자가 글을 작성·발행해 목록에서 확인하고, 댓글을 달고 지운다.

**Blocked by:** 01 — E2E 하네스 부트스트랩

**Status:** ready-for-agent

- [ ] 목록→뷰어: API로 만든 글이 목록에 보이고 클릭하면 뷰어에 제목·본문 렌더
- [ ] 관리자 로그인 UI: 로그인 페이지에서 admin 계정 입력 → 로그인 성공 (storageState 미사용 테스트)
- [ ] 글 작성→발행: 작성 화면에서 제목·본문 입력 → 발행 → 목록에 노출
- [ ] 댓글: 글에 댓글 작성 → 표시 확인 → 삭제 → 사라짐 확인
- [ ] 콘텐츠는 각 테스트가 API로 생성 (시드 글 의존 금지)
