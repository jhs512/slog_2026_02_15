# 03 — 실시간 시나리오

**What to build:** 브라우저 컨텍스트 2개(구독자/행위자)로 실시간 축을 검증한다: 어떤 글이 조회수 10을 돌파하는 순간 구독자 화면에 새글 알림 토스트가 뜨고(작성자 본인에게는 안 뜨고), 글 상세를 보는 중 다른 쪽에서 수정하면 본문이 실시간 반영된다.

**Blocked by:** 01 — E2E 하네스 부트스트랩

**Status:** ready-for-agent

- [ ] SSE 알림: 글 생성(published) 후 비로그인 API 조회 10회 → 구독자 브라우저에 토스트(제목 포함) 표시, 9회까지는 미표시
- [ ] 본인 제외: 작성자 브라우저에는 같은 이벤트에서 토스트가 뜨지 않음
- [ ] STOMP 반영: 글 상세를 열어둔 브라우저에서, 다른 컨텍스트가 글을 수정하면 새 본문이 리로드 없이 표시
- [ ] 알림 토스트 컴포넌트가 전역에 마운트되어 있는지 확인 — 안 되어 있으면 마운트 수정이 이 티켓에 포함됨
- [ ] 대기는 expect 폴링만, 고정 sleep 금지
